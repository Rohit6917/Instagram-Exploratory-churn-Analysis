# 📊 Social Media Data Analysis & Machine Learning Using Python

## 📌 Project Overview

This project focuses on analysing social media data to understand user engagement, interaction patterns, follower activities, photo performance, and user behaviour.

The project uses Python, SQL, and Machine Learning techniques to explore multiple datasets and extract meaningful insights from social media activities.

The primary objective is to perform data cleaning, Exploratory Data Analysis (EDA), SQL-based data analysis, data visualization, and experiment with different machine learning algorithms.

## 🎯 Project Objectives

- Analyse social media user engagement and interaction patterns.
- Understand different types of likes and user activities.
- Examine follower and followee account status.
- Identify trends in follower activities based on time.
- Analyse photo engagement and comment distribution.
- Explore relationships between different datasets.
- Experiment with machine learning algorithms for predictive modelling and clustering.

## 🛠️ Technologies & Libraries Used

- **Python:** Core programming language.
- **Pandas & NumPy:** Data cleaning, manipulation, and preprocessing.
- **Matplotlib & Seaborn:** Data visualization.
- **Pandasql:** SQL queries on DataFrames.
- **Scikit-learn:** Machine learning implementation.
- **TensorFlow / Keras:** Artificial Neural Network implementation.
- **Jupyter Notebook:** Development and experimentation environment.

## 📂 Dataset Description

The project works with six different CSV datasets:

1. **Photos:** Contains photo-related information.
2. **Likes:** Contains user likes and interaction types.
3. **Comments:** Contains user comments and photo-related engagement.
4. **Follows:** Contains follower and followee information.
5. **Tags:** Contains hashtag and location information.
6. **Photo Tags:** Contains relationships between photos, users, and tags.

## 🔍 Project Workflow

### 1. Data Collection & Loading
Imported six CSV datasets using Pandas and explored their structure.

### 2. Data Cleaning & Preprocessing
- Checked missing values.
- Identified duplicate records.
- Handled missing values.
- Converted date columns into datetime format.
- Applied Label Encoding to categorical variables.

### 3. Exploratory Data Analysis (EDA)
Performed analysis to understand:
- Distribution of different like types.
- Follower activities by year, month, and week.
- Followee account status.
- Photo-wise comment distribution.
- Photo and tag relationships.
- User interaction patterns.

### 4. SQL-Based Data Analysis
Used SQL queries through Pandasql to perform:
- SELECT operations.
- GROUP BY and aggregation.
- DISTINCT records.
- INNER JOIN and LEFT JOIN.
- Category-wise counts and summaries.

### 5. Data Visualization
Created different visualizations using Matplotlib and Seaborn, including:
- Count plots.
- Bar charts.
- Histograms.
- Heatmaps.
- Violin plots.
- Pair plots.
- Line plots.

### 6. Machine Learning Implementation

Experimented with multiple machine learning algorithms:

| Algorithm | Purpose |
|---|---|
| Logistic Regression | Classification |
| Linear Regression | Regression |
| Random Forest Regressor | Regression |
| K-Means Clustering | Unsupervised learning |
| Support Vector Machine (SVM) | Classification |
| Artificial Neural Network (ANN) | Deep learning |

Also explored model evaluation using Mean Squared Error (MSE), Mean Absolute Error (MAE), and R² score.
